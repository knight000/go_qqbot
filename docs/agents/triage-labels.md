# Triage Labels

技能用五个固定的 triage 角色说话。下表把它们映射到本仓库实际使用的标签字符串。

| 技能里的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已定稿，可交给 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不做 |

当技能提到某个角色（例如"打上 AFK-ready 标签"）时，使用上表右列的字符串。

标签已在 GitHub 上创建完毕（2026-10-18）。
